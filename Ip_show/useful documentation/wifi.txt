================================================================================
MINIBOT WI-FI & ACCESS POINT SWITCHING CHEAT SHEET
================================================================================
Note: Because Corneille-wifi puts wlan0 into "unmanaged" mode (for hostapd),
always run the "STOP ACCESS POINT" block before connecting to a client Wi-Fi
(LeSeigneurdesAnneaux or OnePlus Nord 2T 5G).

--------------------------------------------------------------------------------
0. STOP ACCESS POINT (Run this FIRST before switching to a client Wi-Fi)
--------------------------------------------------------------------------------
sudo rm -f /etc/NetworkManager/conf.d/99-unmanaged-wlan0.conf
sudo systemctl stop hostapd dnsmasq
sudo dhcpcd -k wlan0 2>/dev/null
sudo rfkill unblock wifi
sudo ip link set wlan0 up
sudo ip addr flush dev wlan0
sudo ip route del default via 10.3.141.1 2>/dev/null
sudo systemctl restart NetworkManager wpa_supplicant
sleep 2
sudo nmcli radio wifi on
sudo nmcli dev set wlan0 managed yes
sleep 3
sudo nmcli dev wifi rescan
echo -e "nameserver 8.8.8.8\nnameserver 1.1.1.1" | sudo tee /etc/resolv.conf > /dev/null

3. MINIBOT ACCESS POINT: Corneille-wifi (IP: 10.3.141.1 | Pass: croacroa)
